# Algoritmos em C e C++

Repositório criado para armazenar exercícios, desafios e projetos desenvolvidos durante meus estudos de lógica de programação e Linguagem C e C++, as pastas estão numeradas por aula e tema principal.

## Conteúdos abordados
- Variáveis
- Entrada e saída de dados
- Estruturas condicionais
- Laços de repetição
- Vetores
- Funções e ponteiros
- Matrizes e funções
- Recursividade e funções

## Objetivo
Desenvolver fundamentos de programação, raciocínio lógico e boas práticas de desenvolvimento.
